# 【v0.1.1での方針転換】
#   v0.1.0では numpy / scipy / PyYAML なども含めて全パッケージを厳密に
#   "==" でピン留めしていましたが、Google Colab実機でのテストにより、
#   Colabのベースイメージに既に入っているパッケージ(PyYAML等)を
#   異なる厳密バージョンで上書きインストールしようとした際に、
#   ソースからのビルドが発生して失敗する不具合が確認されました
#   ( "python setup.py egg_info did not run successfully" エラー。
#     原因の詳細は README.md のトラブルシューティング参照)。
#
#   このため、v0.1.1からは以下の方針に変更します。
#     - numpy / scipy は requirements.txt に含めない
#       (Colabの「ランタイムバージョンの固定」機能で既にバージョンが
#        固定されているため、ここで別バージョンを指定すると衝突の原因に
#        なります)
#     - それ以外のパッケージも、動作実績のある最小バージョンのみを
#       ">=" で指定し、厳密な "==" ピン留めはしません
#       (厳密な再現性は requirements.txt ではなく、Colab上で実際に
#        動作確認した結果を書き出す requirements-lock.txt の役割とします。
#        詳細はREADME.md参照)
# =============================================================================
