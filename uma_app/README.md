# uma_app — UMA(機械学習ポテンシャル)版

機械学習ポテンシャル **UMA**(Meta FAIR Chemistry)で、構造最適化と振動数解析を行います。
入口は、リポジトリ直下の `ColabApp_UMA.ipynb`(画面は `gui_uma.py`)です。
PySCF版(`ColabApp.ipynb` / `gui.py` / `qcapp/`)とは独立しており、お互いに影響しません。

**計算結果は、機械学習による高速な予測値であり、DFT等の量子化学計算そのものの値ではありません。**

## ファイル構成

| ファイル | 役割 |
|---|---|
| `uma_engine.py` | Hugging Faceのトークン・アクセス確認、モデル(predictor)の読み込み、ASEのAtoms/Calculator作成 |
| `uma_optimize.py` | ASE(LBFGS等)+UMAによる構造最適化。結果の項目名は `qcapp/optimize.py` とそろえてある |
| `uma_freq.py` | 数値微分によるHessianと、並進・回転を除いた調和振動数解析(純粋なnumpy) |
| `uma_notice.py` | UMAの利用条件・結果の性質・引用の注意書き(GUI・ログで共通利用) |
| `uma_report.py` | ダウンロード用ログの本文の組み立て |
| `../gui_uma.py` | GUIの組み立て(PySCF版の `gui.py` に相当) |
| `../config/uma_defaults.yaml`, `uma_models.yaml` | 既定値・選べるモデル(PySCF版の設定とは別ファイル) |
| `../requirements-uma.txt` | UMA版の依存ライブラリ(PySCF版の `requirements.txt` とは別) |

`common/`(構造の読み込み・検証、xyz出力、構造・振動の表示、ドラッグ&ドロップ、クリックできるグラフ)は
PySCF版と共有しています。`uma_app` は `qcapp` を一切importしません。

## 使い方

`ColabApp_UMA.ipynb` を開き、上から順にセルを実行します。ランタイムは **T4 GPU・ランタイムバージョン 2026.07**
を前提にしています。Hugging Faceのアカウント作成・UMAの利用条件への同意・トークンの発行が必要です
(ノートブックの「3.」に手順があります)。

## 設計上のメモ

- **振動数解析を自前実装にした理由**: 設計案ではASEの`Vibrations`を想定していましたが、並進・回転由来の
  ゼロ付近のモードが混ざり、虚振動の数え方が紛らわしくなるため、力の中心差分でHessianを作り、
  並進3+回転3(直線分子は2)を除いた空間で対角化する方式にしました。PySCF版と同じく3N-6個(直線分子は3N-5個)の
  モードが得られます。数値部分は単体テスト(`tests/test_uma_freq.py`)で、二原子分子の解析解・同位体効果・
  回転不変性・直線分子のモード数などと照合しています。
- **収束条件**: 既定は fmax ≤ 0.01 eV/Å(`uma_defaults.yaml`)。振動数計算で小さな虚振動が出にくいよう、
  ASEの既定(0.05)より厳しくしています。最大ステップ数に達しても収束しなかった場合は、エラーにせず
  途中経過を表示します。
- **単位**: エネルギーはGUI・出力では Hartree で扱い(PySCF版と同じ)、ログには eV も併記します。
- **モデル**: 既定は `uma-s-1p2p1`。モデルカードでアーカイブ扱い(既知の不具合あり)の `uma-s-1` は選択肢に載せていません。

## 既知の制約・未実装

- **TS(遷移状態)探索、座標を固定した最適化(スキャン)は未実装**です。
- 構造ファイルの読み込みは `common/io_reader.py` を共有しているため、**H〜Xe**の元素のみ対応です
  (UMAが対応する元素のうち、それより重い元素は現時点で読み込めません)。
- 分子軌道・原子電荷・molden出力はありません(UMAは電子状態を返さないため)。
- **Colab実機での動作確認は未実施です**(fairchem-coreのインストール、Hugging Faceのゲート、UMAの推論、
  ドロップ・クリックのJavaScript連携)。確認項目は、リリース前のチェックリストとして管理してください。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 「UMAのモデルにアクセスできませんでした」 | facebook/UMAでの利用条件への同意・承認済みか、同じアカウントのトークンか、権限にReadがあるか |
| `fairchem-core` のインストールに失敗する | ランタイムバージョンが2026.07か(ノートブック「0.」のセルで確認)。ColabReactionでは `numba==0.60.0` を先に固定している |
| インストール後に「セッションを再起動」の警告が出る | メニューの「ランタイム」→「セッションを再起動」後、「1-b」のセルから実行し直す |
| 計算が非常に遅い | GPUランタイム(T4)になっているか(実行ログに「デバイス: GPU(...)」と出ます) |
| 虚振動が出る | 小さい場合(−50 cm⁻¹以内)は収束不足・数値誤差の可能性。`fmax_ev_per_angstrom` を小さくして再実行 |
