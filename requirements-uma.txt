# 【バージョン指定の考え方】(requirements.txt と同じ方針)
#   このプロジェクトのコードが具体的なAPIの形に強く依存しているものは上限も指定し、
#   次のメジャーバージョンを自動では取り込まないようにする。
#   ごく基本的な機能だけを使うものは下限のみ指定する。
#   初回インストール後は、ColabApp_UMA.ipynb が requirements-uma-lock.txt
#   (実際にインストールされた版の記録)を生成する。
#
# 【torchについて】
#   torch はここには書かない。ランタイムバージョン 2026.07 には PyTorch 2.11.0(+cu128)が
#   入っているが、fairchem-core 2.23.0 のインストール時に 2.13.0 へ更新されることを
#   確認している(2026-10-12、実機でのインストール結果)。更新後のtorchでGPUが使えることは、
#   ノートブックの「2-c」のセルで確認する。
#
# 【ipywidgetsについて】(PySCF版の requirements.txt とは異なり、指定しない)
#   Colab標準のGUI部品の表示の仕組みは ipywidgets 7.x(Colabのランタイムには 7.7.1 が
#   入っている)向けで、8.x に更新するとGUI部品が表示されなくなることがある
#   (「コードスニペット」のパネルが開くだけになる)。そのため、ここでは指定せず、
#   Colab標準のものをそのまま使う。gui_uma.py は 7.x / 8.x のどちらでも動くように
#   書いてある。8.x が入ってしまった場合は、ノートブックの「II-0」のセルが
#   カスタムウィジェットマネージャーを有効にする。
#
# 【インストールを確認した版】(2026-10-12 / ランタイム 2026.07 / T4 GPU)
#   fairchem-core 2.23.0, ase 3.29.0, huggingface_hub 1.23.0, PyYAML 6.0.3, py3Dmol 2.5.5
# =============================================================================
